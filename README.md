# Student Social Media Addiction Analysis

## Project Overview

An interactive Power BI dashboard analyzing student social media usage, addiction patterns, and related behavioral factors.

The project explores usage patterns across students and presents key findings through interactive visualizations and dashboard-based analysis.

## Objectives

- Analyze student social media usage patterns
- Identify factors associated with social media addiction
- Explore behavioral and demographic patterns
- Present insights through an interactive Power BI dashboard

## Analysis & Dashboard

The dashboard includes visual analysis of student social media behavior and addiction-related patterns, allowing users to explore the data through interactive Power BI visuals and filters.

## Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Data Analysis
